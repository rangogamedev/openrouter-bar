# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, and assume good faith. Harassment and personal attacks are not accepted.

To report a problem, open an issue that only asks the maintainer for a private contact (no details in public), or use Security → Report a vulnerability. Reports are handled confidentially.
