## [1.0.0] - 2026-09-18

### Added

- Taskbar widget showing the percent of an OpenRouter key's credit limit that has been used, with a countdown to the limit's reset.
- Docking next to the Claude Code Usage Monitor, and a style that matches it.
- DPAPI-encrypted key storage (`set-key.ps1`), a source-build installer (`setup.ps1`), and optional `settings.ini`.
- Self-test for the parsing, reset-window, and settings logic.
